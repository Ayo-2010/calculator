# Calculator

A calculator that handles everyday arithmetic.

## Features

- Chained operations, decimals, sign toggle and percent
- Calculation history you can click to reuse a result
- Repeat-equals for running totals
- Full keyboard support

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
